Stardance Dev Board

A keypad with 6 keys to help me with programming.

## Features

* ** Has toggle keys to mute and unmute.
* ** Combines a series of short cuts on a regular keyboard to achieve one goal end to end.
* ** Github key
* ** Android studio key
* ** Mute Key
* ** Discord Key
* ** Commit And Push Key

## How It Was Built
* ** Onshape for CAD
*  ** KiCAD for PCB design
